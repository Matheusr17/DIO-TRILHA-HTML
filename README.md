# Trilha HTML - Módulo 2

Projeto desenvolvido durante a trilha de HTML da plataforma DIO (Digital Innovation One), com o objetivo de praticar a estruturação de páginas utilizando HTML5.

## Sobre o Projeto

O desafio consiste na criação de um site completo para uma clínica médica fictícia, aplicando conceitos fundamentais de desenvolvimento web, como:

- Estrutura semântica em HTML
- Criação de formulários
- Tabelas
- Navegação entre páginas
- Inserção de mídias
- Organização de layout

O projeto foi desenvolvido com base no repositório disponibilizado pela DIO.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Uso de Inteligência Artificial

As imagens utilizadas no projeto foram geradas com auxílio de Inteligência Artificial para complementar a identidade visual da aplicação.

## Objetivo

Praticar os fundamentos do HTML através da construção de um site multipágina, reforçando conceitos essenciais para o desenvolvimento front-end.
